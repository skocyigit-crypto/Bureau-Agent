## 1. Introduction

**Agent de Bureau** is a comprehensive, AI-powered office management platform developed for French-speaking markets. It lets you manage calls, contacts, tasks, invoices, projects, inventory, and much more from a single place.

### Platform Features
- Web application (all browsers)
- Mobile application (iOS and Android)
- PWA support (install to desktop)
- Multi-tenant architecture (multiple organizations)
- AI integration (Gemini, OpenAI, Anthropic)
- Voice command system

### System Requirements
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Mobile: iOS 15+ or Android 12+
- For voice commands: Chrome browser (best support)

## 15. Approval Queue (File d'approbation)

**Access:** **File d'approbation** from the left menu · **Plus > File d'approbation** on mobile

This screen embodies the application's **core security rule**:

> The AI prepares a task, shows it to you, and **does not carry it out** until you approve it.

If the AI is about to send an email or SMS to a customer, cancel an appointment,
or issue a debt reminder, it first leaves a **suggestion** here.
Nothing goes out that you haven't approved.

### What you see in a suggestion

- **Title and summary** — what will be done
- **"Pourquoi"** (Why) — why the AI is suggesting this (the triggering event)
- **The actual content** — the full text that will go to the customer. The email body, SMS
  text, appointment details... Not a summary, but exactly what will be sent.

### You can edit it before approving

The text fields are **editable**. If you don't like the email the AI wrote,
correct it, then approve — what gets sent is your final version. The approval
window also shows the final values, so before you hit send you see exactly what
will go out.

### Buttons

| Button | What it does |
|---|---|
| **Approuver** (Approve) | Carries out the action immediately (sends the email, cancels the appointment...) |
| **Rejeter** (Reject) | Deletes the suggestion; nothing is done |
| **Lancer l'analyse** (Run analysis) | Asks the AI to generate new suggestions right away |

Suggestions that show a red warning are **irreversible** operations (for example, an appointment
cancellation) — read them twice before approving.

### Tabs

- **En attente** (Pending): those awaiting a decision. The number in the left menu counts these.
- **Historique** (History): what you have approved, rejected, and their outcomes.

> Suggestions older than 14 days that no one has touched automatically become "expiree" (expired) and
> drop off the list. If the situation is still ongoing, the AI will suggest it again with up-to-date
> information.

### What lands here, and what doesn't

**Requires approval** (things that go outside and are hard to undo):
- Email and SMS to customers
- Appointment cancellations requested by phone
- Payment/debt reminders
- Messages that automation rules send to customers

**Does not require approval** (internal, harmless operations):
- In-app notifications
- Task creation
- Record updates

You can change this distinction for automation rules — see section 18.

## 17. Phone System

**Access:** **Telephonie** from the left menu or **Telephonie** on mobile

### Supported Providers
Twilio, Vonage, Telnyx, Plivo, Sinch, Bandwidth

### Features
- Provider configuration
- Placing calls and sending SMS
- Call and SMS history
- Statistics panel

### Adding a Provider

1. On the **Telephonie** page, go to the **Providers** tab and click the **Ajouter un fournisseur** (Add a provider) button
2. Select a provider from the list
3. Enter the information required by the provider:
   - **Twilio:** Account SID, Auth Token, Expediteur (sender) number
   - **Vonage:** API Key, API Secret, Expediteur number
   - **Telnyx:** API Key, Connection ID, Expediteur number
   - **Plivo:** Auth ID, Auth Token, Expediteur number
   - **Sinch:** Project ID, API Token, Service Plan ID, Expediteur number
   - **Bandwidth:** Account ID, Username, Password, Application ID, Expediteur number
4. Save with **Configurer** (Configure), then verify the connection with the **Test** button

> **About the Test button:** This test does not connect to the provider — it only verifies
> that the fields you entered are complete. Even an incorrect Auth Token will appear
> "successful". Real validation happens on the first call or SMS attempt.

### Webhook Integration

Providers automatically report call status updates via webhook. Webhook address: `/api/telephony/webhook/{provider_name}`

### Voice Secretary and Appointment Cancellation

The AI secretary answers incoming calls, takes appointments, and records messages.

**If a caller wants to cancel an appointment**, the secretary does not carry out the cancellation
itself. It leaves the request in the **File d'approbation** screen and tells the caller,
"I have passed your request along; we will confirm shortly." The appointment is only cancelled
after you approve it.

**Why it works this way:** The identity of the person on the phone consists only of the name they
state and the calling number; both can be spoofed. An appointment cancellation, meanwhile, is
irreversible and directly affects the customer. That is why the decision is left to a human.

Cancellation requests appear in the approval queue with a **red warning**. See section 15.

## 18. Automation

**Access:** **Automatisations** from the left menu or **Automations** on mobile

Create rules to automate repetitive operations:
- Select a trigger event (e.g., new call, task overdue)
- Set the conditions
- Define the action (e.g., send notification, create task)

### Approval policy

Each rule's card has a badge. You can **click on it** to change the policy —
three options cycle in turn:

| Badge | Meaning |
|---|---|
| **Envois a valider** (default) | Email/SMS going to customers drops into the approval queue; notifications and task creation run automatically |
| **Tout a valider** | Everything, including internal operations, awaits approval |
| **Tout automatique** | Nothing awaits approval; the rule applies directly |

**Why the default is set this way:** You write a rule once, but that rule then runs
**on its own every 5 minutes** afterward. No one would have read every message sent to a customer.
The default setting puts anything leaving the organization in front of human eyes; it does not
slow down internal operations.

Rule actions awaiting approval appear in the **File d'approbation** screen with the final version
of the text to be sent (with customer name, date, etc. filled in) — not a template, but exactly
what will go out. See section 15.

## 23. Administration Panel

### Organizations (Super Admin only)
**Access:** **Organisations** from the left menu
- Adding, editing, and deleting organizations
- Generating license keys
- Subscription management

#### Creating a new organization

Start typing the company name in the **Nom de l'organisation** (Organization name) field (at least 2 letters).
The application searches the official French company register and opens a list. When you select
from the list, the **official title, address, and SIRET** are filled in automatically.

If the register is unreachable, the list comes up empty — you can keep typing manually, and nothing
is blocked.

When you complete the form with **Creer et envoyer** (Create and send), the organization is created and
the license key + administrator login credentials are sent by email.

#### If the email doesn't go through

The organization is created but a **red warning** appears and states the **actual error**
(for example, the sender domain is not verified, or the API key is missing). The window closes —
because the organization already exists, and resubmitting the form would create a duplicate.

The license is not lost: using the **Renvoyer la licence** (Resend license) button on that
organization's row in the list, you can resend it after fixing the problem.

#### Monthly invoices (draft approval)

Platform invoices are generated automatically each month but wait as a **draft**;
they do not enter any debt/overdue account. They are finalized only after a super admin reviews
and approves them. This is designed so that financial documents don't reach the customer without
a human seeing them.

> Note: Invoice drafts do not appear in the approval queue (section 15) — that queue is specific
> to the organization, and the tenant would be approving its own invoice. Draft approval is on
> the super admin's side.

### Health Check / Sante technique (Super Admin only)
**Access:** Left menu > Super Admin > **Sante technique**

7 agents that continuously audit the application's **infrastructure**. Each agent is responsible
for its own area and runs automatically every 15 minutes. You can also run them manually anytime
with **Verifier maintenant** (Check now).

| Agent | What it checks |
|---|---|
| **Base de donnees** | Connection pool saturation, query latency, Postgres connection count |
| **Services externes** | A **real** connection test to Resend / Gemini / Twilio / Stripe / Google |
| **Configuration** | Missing environment variable, incorrect OAuth address, NODE_ENV |
| **Taches planifiees** | Liveness tracking of scheduled jobs (detecting dead cron) |
| **Taux d'erreurs** | 500 and 429 response rates |
| **Ressources serveur** | Memory, CPU congestion, uptime |
| **Integrite des donnees** | Orphan records, structural inconsistencies |

Each finding is in one of three states: **OK** (green), **Degrade** (orange, needs attention),
**En panne** (red, faulty). For problematic findings, **what needs to be done** is also stated.

**Why this screen exists:** Business-data checks (overdue tasks, silent customers) cannot see an
infrastructure failure. Real examples that have happened: the database connection pool filling up
brought every page down with 500 errors; an unverified domain silently blocked emails from going
out; a misconfigured request limit locked the entire application with 429s. This screen catches
those kinds of failures before the user notices.

## 26. Frequently Asked Questions

### I forgot my password, what should I do?
On the login screen, contact your system administrator. A Super Admin can reset your password.

### Does the AI send emails or SMS to customers on its own?
No. Nothing that leaves the organization is sent without your approval. The AI prepares
the text and leaves it in the **File d'approbation** screen; you read it, correct it if needed,
then approve it (see section 15). The same rule applies to appointment cancellations requested
by phone and to payment reminders.

**Internal** operations such as in-app notifications and task creation do not await approval —
they don't reach anyone outside. If you wish, you can make automation rules
"Tout a valider" to put those under approval as well (section 18).

### There are items waiting in the approval queue but I'm not noticing them?
The number of pending items appears next to **File d'approbation** in the left menu; on mobile,
the same number appears in the **Plus** menu. Suggestions untouched for 14 days automatically
drop off — if the situation is still ongoing, the AI will suggest it again with up-to-date
information.

### The license email didn't go through, what should I do?
If a red warning appeared after the organization was created, the text in that warning states
the **actual reason** (usually the sender domain being unverified or a missing API key). After
resolving the reason, resend it using the **Renvoyer la licence** button on the organization's
row — the license is not lost.

### If voice commands don't work?
- Make sure you are using the Chrome browser
- Check the microphone permission (the lock icon in the browser's address bar)
- Try speaking French (the system performs French recognition)

### Why doesn't the voice assistant work in the mobile app?
Voice recognition currently works best in a web browser. In the native mobile app, you can use the same functions by selecting from the command list.

### Is my data secure?
Yes. The platform uses a 9-layer security architecture:
- Authentication and authorization
- Helmet security headers
- Rate limiting
- Strict CORS policy
- AES-256-GCM encryption (for backups)
- Audit log

### How is an invoice PDF generated?
On the invoice detail page, click **Telecharger PDF** (Download PDF) or the print icon.

### How do I connect Google Calendar?
Set up a connection via OAuth2 authorization through Settings > Plateformes > Google.

### How can I manage multiple organizations?
If you have the Super Admin role, you can add and manage multiple organizations from the
**Organisations** page. Each organization has an isolated tenant.

- You can achieve faster access by installing it as a PWA
- You can diagnose slow requests from Chrome DevTools > Network tab
